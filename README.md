About me

I am a software engineer focused on building reliable full-stack products, enterprise applications, and scalable SaaS platforms. My core backend stack is Java/Spring Boot and Python/Django, paired with Angular, React, and Next.js for modern web experiences.

My work spans secure API design, multi-tenant architecture, asynchronous processing, enterprise integrations, AI-assisted workflows, and production deployment. I enjoy taking a product from an initial business need to a clean, maintainable, and deployable solution.
